- ▶️ **کنترل بات**: Run / Stop / Restart با یک کلیک
- 🐛 **دیباگ خودکار**: خودش مشکلات رو پیدا و فیکس میکنه

- 🔐 **امنیت**: ورود با پسورد (ADMIN_PASSWORD)

## 🚀 نصب روی ریلوی - خیلی ساده (3 دقیقه)

### مرحله 1: آماده سازی اطلاعات
از اینا نیاز داری:
1. **API_ID و API_HASH**: برو https://my.telegram.org -> API development tools -> بساز
2. **OWNER_ID**: آیدی عددی خودت، از ربات @userinfobot بگیر
3. **SESSION_STRING (اختیاری ولی پیشنهادی)**: 
   - راحت‌ترین راه: یک بار پروژه رو لوکال ران کن، بعد از لاگین، فایل `my_account.session` ساخته میشه، یا
   - از ربات‌های Session String Generator استفاده کن
4. **ADMIN_PASSWORD**: یه پسورد قوی برای داشبوردت بذار

### مرحله 2: پوش به گیت‌هاب و اتصال به ریلوی
1. این پروژه رو به گیت‌هاب خودت پوش کن (همین ریپو `SElf`)
2. برو https://railway.app -> New Project -> Deploy from GitHub repo
3. ریپو `SElf` رو انتخاب کن، برنچ `arena/01a10818-self` یا `main`

**یا اگر از قبل پروژه روی ریلوی داری (مثل شاد سلف قبلی):**
1. برو داخل پروژه قبلی در ریلوی
2. Settings -> Service -> Source -> Connect Repo رو بزن و همین ریپو رو وصل کن
3. یا ساده‌تر: فایل‌های جدید رو جایگزین قبلی کن و Redeploy بزن

### مرحله 3: تنظیم Variables در ریلوی
برو تب **Variables** و اینا رو اضافه کن:

```
API_ID=12345678
API_HASH=your_api_hash
OWNER_ID=123456789
ADMIN_PASSWORD=یه_پسورد_قوی_بذار
SESSION_STRING=اختیاری_اگه_داری
SESSION_NAME=my_account
AUTO_START_BOT=true
```

> **نکته مهم**: `PORT` رو خود ریلوی میده، دستی نذار!

### مرحله 4: اضافه کردن Volume (خیلی مهم!)
برای اینکه سشن و دیتا پاک نشه:

1. تب **Settings** -> **Volumes** -> **New Volume**
2. Mount Path بذار: `/app/data`
3. یا `/app` رو کلاً Volume کن (اگر میخوای همه چیز بمونه)

اگر Volume نذاری، بعد هر ری‌استارت باید دوباره لاگین کنی!

### مرحله 5: دیپلوی و لذت!
- روی **Deploy** بزن
- بعد 1-2 دقیقه بالا میاد
- از تب **Deployments** -> **View Logs** لاگ رو ببین
- دامنه رو باز کن: `https://your-app.up.railway.app`
- با پسوردی که گذاشتی وارد داشبورد شو
- دکمه **Run** رو بزن تا بات روشن بشه


## 🔧 عیب یابی (Debug)

اگر بات روشن نشد:

1. برو داشبورد -> دکمه **🐛 دیباگ خودکار** رو بزن
2. بهت میگه چی کمه:
   - API_ID نذاشتی؟
   - سشن نداری؟
   - فایل data ناقصه؟ (خودش میسازه)
   - دیسک پره؟

**مشکلات رایج:**

- **بات کرش میکنه**: لاگ رو ببین (تب لاگ زنده). معمولا API_ID اشتباهه
- **سشن پاک میشه**: Volume نذاشتی، حتما `/app/data` رو Volume کن
- **داشبورد 401 میده**: پسورد رو درست وارد کن، یا ADMIN_PASSWORD رو چک کن
- **TimeName کار نمیکنه**: از داشبورد سوییچش رو on کن
